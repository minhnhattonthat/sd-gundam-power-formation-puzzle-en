# Glossary - SD Gundam Power Formation Puzzle

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.

## Rulings (user, 2026-10-10, same as earlier project for this game)
- Official Gundam terms and names. No honorifics; Western name order (no personal names appear so far).
- Credits/copyright in English. Full words, no abbreviations; prefer engine work (it gave 26 chars/line here).
- Routine decisions pre-approved.

## Style rules
- Punctuation: 「」 -> "...", ・・ / ・・・ -> ..., ！ -> !, ！！ -> !!, ？ -> ?, 。 -> . (keep the JP mood: 。 stays a period).
- Briefings are narration, present tense where the JP is ongoing (しかけてきた -> "have launched an attack").
- Endings B41/B42 are rough, hot-blooded first person (ブチのめした, 強いヤツ): "smashed", "someone even stronger".
- Line width: 26 chars (briefing/ending/prologue). Keep the JP paragraph layout (blank line between paragraphs).
