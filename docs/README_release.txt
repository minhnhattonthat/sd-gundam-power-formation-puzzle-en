SD Gundam Power Formation Puzzle - English translation patch v{version}
=========================================================================

Unofficial fan translation of the 1996 Super Famicom puzzle game by Bandai.
No ROM is included or distributed. Patch your own dump.

What is translated
- Intro text, all 45 story-mode mission briefings (three teams), all 8 endings,
  the Options menu and the boot copyright screen.
- The rest of the game (menus, unit select, battle) was already in English.
- New 8x16 English font; briefings and endings show 26 characters per line,
  and finished briefings stay on screen a few seconds longer so they can be read.

How to patch
1. Get the original ROM (No-Intro: "{orig}"):
     size {orig_size} bytes (no copier header)
     {orig_hash}
2. Apply {bps} with Flips, beat or Rom Patcher JS.
3. Result: {patched_size} bytes (2 MiB, expanded)
     {patched_hash}

Tested in Mesen2 (cold boot). Start from a fresh boot, not an old savestate.

Notes
- Gundam terms follow official usage (Zeon, Titans, OZ, Neo Zeon, Mobile Fighter, Gundam Fight).
- One faction name in three briefings (written "CV Sansugaaru" in the Japanese text, limited by the font)
  is translated as "Crossbone Vanguard and Zanscare".
